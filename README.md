# AI Novel Studio

一个本地 Electron 工具：配置 OpenAI 兼容模型接口 → 检测可用模型 → 输入小说名与章节数 → 自动生成并保存到本地，并提供“番茄作家后台（实验）”注入发布能力。

## 开发

```bash
cd ai-novel-studio
npm install
npm run dev
```

## 使用

1. 进入「设置」
   - `Base URL`：你的模型网关地址（会自动拼接 `/v1`）
   - `API Key`：可选（本地加密存储）
   - 点击「检测模型」，选择一个 `模型 ID`，再点「保存」
2. 进入「创作中心」
   - 输入小说名与章节数
   - 建议先 10-30 章试跑；本工具支持 100+ 章长跑（耗时更久，建议网络稳定/配额充足）
   - 点击「开始生成」
3. 生成结果默认保存到：`Documents/AI Novel Studio/`

## 账号与本地数据

- 账号仅保存在本地，不依赖服务器。
- 首次启动会自动生成默认超管账号：`admin / admin123456`（可在“用户管理”里修改或新增）。
- 余额与账单为本地账本，仅用于演示或估算，不涉及真实支付。

## 番茄发布（实验）

目前没有使用官方发布 API（如站点未提供公开接口，“一键发布”只能通过页面自动化/注入实现，可能随页面改版失效，也可能触发平台风控）。你需要自行确保符合番茄作家后台的规则与条款。

建议流程：
1. 在「设置」里点「打开发布窗口」
2. 登录后进入“新建章节/发布章节”的编辑页面
3. 回到「创作中心」对某一章点击「注入」或「注入并尝试发布」
